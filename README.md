# 자율실험실(SDL) 도식 – 자율실험 폐루프 예시 이미지 추가

`v4_new_mod` 도식의 **자율실험 폐루프** 안 1~4번 박스에 각 단계를 설명하는
예시 이미지를 추가한 버전입니다. **텍스트 내용은 원본과 100% 동일**하며
(텍스트 런 227개 전부 일치), 이미지 삽입 공간을 확보하기 위한
레이아웃(여백·박스 높이·연결선 위치)만 조정했습니다.

## 두 가지 버전

| 버전 | 파일 | 이미지 |
|---|---|---|
| **A. 일러스트** | `자율실험실_SDL_도식_v5_예시이미지.pptx` | 직접 제작한 벡터 일러스트 (박스당 3분할 스트립 1장) |
| **B. 사진** | `자율실험실_SDL_도식_v5-photo_사진버전.pptx` | 실제 사진 (박스당 3장, 총 12장) |

> **B(사진 버전)는 현재 자리표시자 상태입니다.** 이 작업 환경의 네트워크 정책이
> Wikimedia Commons·Unsplash·Pexels·Pixabay 등 모든 이미지 호스트를 차단하고 있어
> 사진을 내려받을 수 없었습니다. `photos/` 에 사진 12장을 넣고
> `python3 assets/apply_photo_layout.py` 를 실행하면 완성됩니다.
>
> **→ 먼저 `사진_넣는_안내표.png` 를 보세요.** 12칸 각각에 대해
> 파일명 / 실제로 무엇이 찍힌 사진이어야 하는지 / 검색어 / 사진 난이도를 정리했습니다.
> PPTX 안의 자리표시자에도 같은 내용이 찍혀 있어, 확대하면 어느 칸에 무엇을
> 넣는지 바로 보입니다.
>
> 12칸 중 `box1_1`(AI 추천엔진) · `box3_2`(목표충족 자동판정) · `box4_2`(파인튜닝 파이프라인)은
> **실물이 없는 개념이라 사진으로 표현이 안 됩니다.** 이 3칸만 일러스트를 쓰는
> 혼합안을 권합니다.

박스의 `ex.` 항목을 그대로 시각화했습니다.

| 박스 | 좌 | 중 | 우 |
|---|---|---|---|
| 1. AI 실험 설계 | AI 추천엔진 | 과거 실험 DB | 가상실험 모델 |

| 4. AI 모델 갱신 | 모델 재학습 | 파인튜닝 파이프라인 | 다음조건·종료 결정 |

## 버전 A – 일러스트

전량 **직접 제작한 원본 SVG 벡터 일러스트**입니다. 외부 스톡 이미지·아이콘 폰트를
사용하지 않았으므로 저작권·라이선스 제약이 없습니다. 원본 도식의 팔레트
(`#1D3567` `#21407C` `#1B54B5` `#C7D4EC` `#F4F6FA` `#DDE0E6`)를 그대로 사용해
기존 디자인과 톤을 맞췄습니다. 박스당 이미지 1장(2.625" × 0.62")입니다.

## 버전 B – 사진

같은 이미지 밴드를 **사진 3장(각 0.8383" × 0.58", 약 3:2)** 으로 나눴습니다.

- 원본 사진 비율과 무관하게 **가운데 기준 자동 크롭**(`srcRect`)됩니다. 세로 사진도 됩니다.
- 각 사진은 독립 도형이라 PowerPoint에서 **[그림 바꾸기]로 개별 교체**할 수 있습니다.
  (스크립트를 다시 돌리지 않아도 됩니다)
- 모서리 라운딩 + 얇은 테두리(`#DDE0E6`)를 적용해 카드 디자인과 통일했습니다.

## 레이아웃 변경 내역 (두 버전 공통)

이미지 밴드(카드당 2.625" × 0.62")를 넣기 위해 세로 공간 약 1.5"를 확보했습니다.

- 1~4번 카드 높이 **1.62" → 2.372"** (텍스트 아래에 이미지 밴드 배치)
- 상단 여백 0.71" → 0.22", `개념`/`정의` 박스 높이 0.85" → 0.64"
- `연구자` 박스, 폐루프 컨테이너 내부 여백, 하단 `자동화 실험실과의 차이` 박스 높이 축소
- 폐루프 컨테이너 높이 5.0" → 6.46", 순환 화살표·점선 연결선·우측 지원 요소
  (`표준 인터페이스·드라이버`, `AI-Ready 데이터`)를 새 행 위치에 맞춰 재정렬
- 1번 카드의 `ex.` 텍스트 상자 폭만 2.33"로 좁아 줄바꿈이 과했던 문제를
  나머지 카드와 동일한 2.625"로 정렬 (원본 불일치 수정)
