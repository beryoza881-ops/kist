# 자율실험실(SDL) 도식 – 자율실험 폐루프 예시 이미지 추가

`v4_new_mod` 도식의 **자율실험 폐루프** 안 1~4번 박스에 각 단계를 설명하는
예시 이미지를 추가한 버전입니다. **텍스트 내용은 원본과 100% 동일**하며
(런 단위 비교 결과 227개 텍스트 런 전부 일치), 이미지 삽입 공간을 확보하기 위한
레이아웃(여백·박스 높이·연결선 위치)만 조정했습니다.

## 산출물

| 파일 | 설명 |
|---|---|
| `자율실험실_SDL_도식_v5_예시이미지.pptx` | 최종 결과물 |
| `preview.jpg` | 렌더링 미리보기 |
| `assets/원본_v4_new_mod.pptx` | 입력 원본 |
| `assets/make_example_images.py` | 예시 이미지(SVG→PNG) 생성 스크립트 |
| `assets/apply_layout.py` | 레이아웃 재조정 + 이미지 삽입 스크립트 |
| `assets/example_images/box1~4.svg / .png` | 삽입된 예시 이미지 원본 |

## 추가한 예시 이미지

각 박스의 `ex.` 항목을 그대로 시각화한 3분할 일러스트 스트립입니다.

| 박스 | 구성 (좌 → 우) |
|---|---|
| 1. AI 실험 설계 | AI 추천엔진(신경망) · 과거 실험 DB · 가상실험 모델(분자·시뮬레이션) |
| 2. 로봇·장비 실험 수행 | 로봇팔 · 액체 핸들러 + 웰플레이트 · 측정장비 |
| 3. AI·분석SW의 결과분석 | 측정데이터 곡선 분석 · 목표 충족여부 자동판정 · 결과 시각화 대시보드 |
| 4. AI 모델 갱신 | 모델 재학습(순환) · 파인튜닝 파이프라인 · 다음 실험조건/종료 결정 |

### 라이선스
전량 **직접 제작한 원본 SVG 벡터 일러스트**입니다. 외부 스톡 이미지·아이콘 폰트를
사용하지 않았으므로 저작권·라이선스 제약이 없습니다. 원본 도식의 팔레트
(`#1D3567` `#21407C` `#1B54B5` `#C7D4EC` `#F4F6FA` `#DDE0E6`)를 그대로 사용해
기존 디자인과 톤을 맞췄습니다.

## 레이아웃 변경 내역

이미지 밴드(카드당 2.625" × 0.62")를 넣기 위해 세로 공간 약 1.5"를 확보했습니다.

- 1~4번 카드 높이 **1.62" → 2.372"** (텍스트 아래에 이미지 밴드 배치)
- 상단 여백 0.71" → 0.22", `개념`/`정의` 박스 높이 0.85" → 0.64"
- `연구자` 박스, 폐루프 컨테이너 내부 여백, 하단 `자동화 실험실과의 차이` 박스 높이 축소
- 폐루프 컨테이너 높이 5.0" → 6.46", 순환 화살표·점선 연결선·우측 지원 요소
  (`표준 인터페이스·드라이버`, `AI-Ready 데이터`)를 새 행 위치에 맞춰 재정렬
- 1번 카드의 `ex.` 텍스트 상자 폭만 2.33"로 좁아 줄바꿈이 과했던 문제를
  나머지 카드와 동일한 2.625"로 정렬 (원본 불일치 수정)
