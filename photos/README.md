# 사진 넣는 곳

레포 루트의 **`사진_넣는_안내표.png`** 를 먼저 보세요. 12칸이 어디에 어떤 순서로
들어가는지 그림으로 정리돼 있습니다.

여기에 아래 파일명 그대로 사진을 저장하고
`python3 assets/apply_photo_layout.py` 를 실행하면 사진 버전 PPTX가 다시 만들어집니다.
확장자는 `.jpg` `.jpeg` `.png` `.webp` 모두 됩니다. 12장을 다 채우지 않아도 되고,
넣은 것만 교체되고 나머지는 자리표시자로 남습니다.

## 사진으로는 안 되는 3칸

`box1_1`(AI 추천엔진), `box3_2`(목표충족 자동판정), `box4_2`(파인튜닝 파이프라인)은
**실물이 없는 소프트웨어 개념**입니다. 어떤 사진을 넣어도 결국 "모니터 앞에 앉은 사람"
스톡 사진이 되어 옆 칸과 구분이 안 됩니다.

→ 이 3칸만 일러스트 버전(`자율실험실_SDL_도식_v5_예시이미지.pptx`)의 그림을 쓰는
**혼합안**을 권합니다. 필요하면 만들어 드립니다.

## 사진 규격

- **비율은 신경 쓰지 않아도 됩니다.** 어떤 비율이든 타일 비율(0.8383" × 0.58", 약 3:2)에
  맞춰 **가운데 기준으로 자동 크롭**됩니다. 세로 사진도 됩니다.
- 권장 해상도: 가로 1200px 이상. 인쇄 크기가 작아(약 2×1.5cm) 그 이상은 불필요합니다.
- 피사체가 사진 가운데에 오도록 찍힌 것이 가장 잘 나옵니다.
- 넣은 뒤 PowerPoint에서 위치를 미세 조정하고 싶으면, 그림 선택 →
  [그림 서식] → [자르기]에서 조정하면 됩니다.
