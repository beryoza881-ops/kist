## 사진 규격

- **비율은 신경 쓰지 않아도 됩니다.** 어떤 비율이든 타일 비율(0.8383" × 0.58", 약 3:2)에
  맞춰 **가운데 기준으로 자동 크롭**됩니다. 세로 사진도 됩니다.
- 권장 해상도: 가로 1200px 이상. 인쇄 크기가 작아(약 2×1.5cm) 그 이상은 불필요합니다.
- 피사체가 가운데에 오도록 찍힌 사진이 가장 잘 나옵니다.

## 라이선스 안내

무료로 쓸 수 있는 사진 출처:

- **Wikimedia Commons** (commons.wikimedia.org) — 퍼블릭 도메인 / CC0 / CC-BY.
  CC-BY·CC-BY-SA는 **출처 표기 의무**가 있으니 슬라이드 하단이나 별도 출처 슬라이드에 표기하세요.
- **Unsplash / Pexels / Pixabay** — 상업적 이용·수정 허용, 출처 표기 불필요(권장).
- 논문·제조사 홈페이지 사진은 대부분 **사용 불가**입니다. 반드시 라이선스를 확인하세요.

검색어 예: `laboratory robot arm`, `automated liquid handler`, `pipetting robot`,
`96 well plate`, `mass spectrometer`, `chromatography`, `server rack`,
`molecular simulation`, `data dashboard`, `GPU server`
