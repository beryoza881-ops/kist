# 자율실험실(SDL) 정책 조사·설계 문서

과학기술정보통신부 자율실험실 관련 전략문서 작성을 위한 조사 결과와 설계안 모음.

> **모든 문서의 공통 규칙**
> - **조사 결과**(공개 출처가 있는 사실)와 **자체 제안**(미공표 설계안)을 문서 안에서 명시적으로 구분
> - 각 문서 말미에 **한계**(확인하지 못한 것, 원문 대조가 필요한 것)와 **출처**를 병기
> - 자체 제안 부분은 정부·협의체의 공식 계획으로 인용 불가

## 문서 전체를 관통하는 판단 세 가지

1. **국제표준을 채택하고 국내 프로파일만 정의한다.** 독자 규격을 만들면 벤더 구현 부담이 2배가 되어 아무도 따르지 않는다.
2. **공급이 아니라 수요를 확정한다.** 표준·장비·서비스 모두, 만들어 놓는 것보다 사줄 곳을 정하는 쪽이 먼저다(EMR 인증제가 4년 만에 100배 확산된 이유).
3. **없는 것을 새로 만들기보다 있는 그릇에 얹는다.** 심의는 첨단혁신장비 얼라이언스, 도입은 조달청 혁신제품, 중개는 ZEUS, 보안은 개정 혁신법의 민감과제 분류.
