### 【참고】 국내외 자율실험 서비스산업 현황

**□ (개념)** 연구자·기업이 **실험설비를 직접 보유하지 않고** AI·로봇 기반 실험을 서비스로 이용하는 산업으로, 실험 가치사슬 중 **어느 구간을 서비스로 제공하는지**에 따라 4개 유형으로 구분

*〈그림〉 자율실험 서비스산업 구조 — 개념도 삽입*

**□ (해외 동향)** 클라우드랩·AI 자율실험 기업이 **이미 상업 서비스 중**이며, 대규모 민간자본이 집중

| 유형 | 기업(국가) | 주요 내용 |
|---|---|---|
| ② 실험대행 | **Emerald Cloud Lab** (美) | 오스틴 소재 원격제어 생명과학 실험실. 전 세계에서 접속해 시료 전처리·바이오어세이·DNA/펩타이드 합성·바이오이미징·바이오소재 특성분석 의뢰 |
| ② 실험대행 | **Arctoris** (英) | 원격 실험 기반 기술형 다국적 CRO |
| ③ 운영SW | **Strateos** (美) | 캘리포니아 2개 자동화 실험실 운영, Eli Lilly와 협력. **자체 클라우드랩 확장 대신 고객 시설에 SW를 배치하는 방향으로 전환 중** |
| ④ AI 통합 | **Lila Sciences** (美) | '25년 2억 달러로 출범, 누적 **5.52억 달러** 조달. 엔비디아 참여로 기업가치 **13억 달러**, 최근 85억 달러 가치 협의 보도 |
| ④ AI 통합 | **Periodic Labs** (美) | 前 OpenAI·DeepMind 연구자 창업, 소재 분야. 약 **70억 달러** 기업가치 협의 보도 |
| ④ AI 통합 | **Chemify** (英) | '22년 글래스고 창업. '케뮤테이션'(화학 프로그래밍 언어+로봇+AI). '25년 **1,600만 달러** 규모 자동합성시설 개소, 시리즈B **5,000만 달러**+. **20대 제약사 중 6곳**과 제휴, 합성경로 탐색을 수개월→수시간~수주로 단축 |
| ④ AI 통합 | **XtalPi** (中) | '24년 홍콩증시 상장. 24시간 가동 로봇 실험실로 데이터 축적→AI 학습. **'25년 상반기 매출 5.17억 위안(전년比 +403.8%)**, 조정 순이익 1.42억 위안으로 반기 첫 흑자 |
| ① 장비·모듈 | **Ginkgo Bioworks** (美) | 사내 10년간 사용한 **재구성형 자동화 카트(RAC)** 를 '24년 중반부터 상용 판매. 레고식 모듈로 신규 유닛 추가 10분, 납품→가동 1일 |

**□ (시장 규모)**
- **실험실 자동화** : '26년 **63~101억 달러**(조사기관별 상이), 연평균 **7~9%** 성장
- **자율실험실 포함** : '25년 60억 달러 → **'35년 200억 달러**(CAGR **12.8%**)
- **글로벌 CRO 서비스** : '26년 약 **930억 달러** → '31년 **1,403억 달러**(CAGR 8.6%)
  → 자율실험 서비스가 **대체·재편할 잠재시장**

**□ (국내 현황)** **장비·SW 공급 중심**이며, 실험대행(②)·AI 통합형(④) 서비스는 **사실상 공백**

- **에이블랩스** : '21년 설립, 액체 핸들링 자동화 로봇·SW → **자율실험실(SDL)로 플랫폼 확장 중**
  - '26.8월 **시리즈A 121억원** 유치 / '25년 매출 12.9억원(**전년比 +113%**) / **'26년 상반기 수주액이 전년 매출의 2배 초과**
  - 바이오를 넘어 **반도체·화학·화장품·이차전지 4개 산업** 품질분석 자동화 신규 수주
  - KAIST·부산대·한국화학연구원 등 도입, 美 존스홉킨스대와 오가노이드 약물평가 플랫폼 공동개발
- 자율실험실 산·학·연 협의체 기술·플랫폼·표준 분과에 **파크시스템스·에이치비솔루션·에이블랩스·로봇앤드디자인** 등 장비·자동화 기업 참여

**□ (실험대행 사업자 — 자율/자동화 기반)** 원격 의뢰형(LaaS)과 자동화 CRO 모두 **이미 다수가 상업 운영 중**

| 구분 | 기업(국가) | 내용 |
|---|---|---|
| **LaaS** | **Ginkgo Cloud Lab** (美) | **'26.3월 출시.** 웹브라우저로 벤치워크를 자율실험 인프라에 이관. 자사 **재구성형 자동화 카트(RAC)** 기반(고정밀 로봇팔·자기부상 시료 이송·산업용 SW), **70종 이상 장비** 원격 접근(시료전처리·액체핸들링·분석판독·보관·배양), AI 에이전트 **'EstiMate'** 탑재 |
| **LaaS** | **Emerald Cloud Lab** (美) | 오스틴 소재 원격제어 생명과학 실험실. 시료 전처리·바이오어세이·DNA/펩타이드 합성·바이오이미징·바이오소재 특성분석 |
| **LaaS** | **Culture Biosciences** (美) | **클라우드 연결 바이오리액터.** 실시간 데이터 분석·모델링으로 바이오공정 스크리닝·최적화 대행 |
| LaaS(전환) | **Strateos** (美) | 캘리포니아 2개 자동화 실험실. **자체 클라우드랩 확장 대신 고객 시설 SW 배치로 전환 중** |
| **자동화 CRO** | **Arctoris** (英) | 로봇 플랫폼 **Ulysses** + 과학자 팀. **Eli Lilly 'Life Science Studio' 자동화 랩 인수**(샌디에이고→옥스퍼드). CRO를 넘어 **PRO(Partnership Research Organisation)** 표방 |
| **자동화 CRO** | **XtalPi** (中) | ABB **GoFa 협동로봇 100대 이상** 도입해 상하이 자동화 시설 구축, 'XtalPi Intelligent Automation' 출범. **'25년 상반기 신약발견 솔루션 4.35억 위안(+615.2%) + 지능형 로보틱스 0.82억 위안(+95.9%)** → 반기 첫 흑자 |

**□ (국내 현황)** **장비·SW 공급과 전통 CRO는 있으나, 둘을 결합한 '자율실험 기반 실험대행'은 공백**

- **공급측** : **에이블랩스**('21년 설립, 액체핸들링 로봇·SW → SDL 확장) — '26.8월 **시리즈A 121억원**, '25년 매출 12.9억원(**+113%**), **'26년 상반기 수주액이 전년 매출의 2배 초과**. 바이오 외 **반도체·화학·화장품·이차전지** 4개 산업 품질분석 자동화 수주. KAIST·부산대·한국화학연구원 도입, 美 존스홉킨스대와 오가노이드 약물평가 플랫폼 공동개발
- **전통 CRO** : 바이오톡스텍(AI 병리분석 효율화 적용), 디티앤씨알오, 우정바이오, 씨엔알리서치, 드림씨아이에스 등 → **자율실험 기반 전환은 초기**
- **국가사업** : **첨단바이오 범용 자율실험실** — 가톨릭대·입셀·로봇앤드디자인·한국기계연구원·셀틱스테크놀로지·중앙대 6개 산학연, **82.5억원(’26.4~’28.12)**, **’28년까지 연구 자동화율 70%** 목표
- 자율실험실 산·학·연 협의체 기술·플랫폼·표준 분과에 파크시스템스·에이치비솔루션·에이블랩스·로봇앤드디자인 등 참여

**□ (시사점)**
1. 해외는 이미 **"실험을 구매하는" 시장**이 형성 — 미·중 모두 **LaaS와 자동화 CRO가 동시에 상업 운영** 중이며, 국내는 **장비 공급과 전통 CRO가 분리된 채 결합되지 않음**
2. **'26.3월 Ginkgo Cloud Lab 출시**는 전환점 — **장비 제조사가 자사 자동화 자산을 그대로 클라우드랩으로 개방**한 모델로, 국내 장비기업(에이블랩스 등)이 취할 수 있는 가장 현실적인 경로
3. 반면 **클라우드랩만으로 출발한 사업자는 고전**(Strateos의 SW 배치 전환) → **자체 실험 수요 또는 장비 사업을 먼저 가진 주체가 서비스로 확장**하는 순서가 유효
4. 국내에는 **이미 CRO 산업 기반이 존재** → 무(無)에서 시작하는 것이 아니라 **기존 CRO의 자동화·AI 전환**과 **장비기업의 서비스 확장**을 잇는 것이 최단 경로
5. 서비스 신뢰성의 근거는 결국 **데이터 신뢰성** → 서비스산업 육성은 **표준·인증 체계 확립과 동시 추진**되어야 실효

## Ⅲ. 분량 조절

**반 페이지로 줄일 때** — 해외 표를 유형별 대표 1개사씩 4행으로 축약(Emerald Cloud Lab / Strateos / Lila Sciences / XtalPi), 시장 규모는 '자율실험실 포함' 1줄만, 시사점은 1·3번만 남긴다.
