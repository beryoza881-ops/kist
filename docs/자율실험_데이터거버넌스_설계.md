## Ⅰ. 해외는 어떻게 저장·공유하는가

### 1-1. 중앙 저장소는 없다 — 연합(federated) 구조

미국·유럽 어디에도 실험데이터를 한곳에 모으는 중앙 저장소는 없다. 데이터는 **생산한 시설이 보관**하고, 공유는 **카탈로그와 공통 API**로 한다.

| 층 | 역할 | 사례 |
|---|---|---|
| **저장** | 데이터 실물은 생산 시설·HPC센터에 남음 | ESRF, Diamond, DESY, NERSC |
| **카탈로그** | **데이터를 저장하지 않고** 검색 가능한 구조화된 기술만 제공 | **SciCat**(PSI·ESS 개발, PaNOSC·ExPaNDS 지원), **ICAT** |
| **연합 API** | 여러 DB를 하나의 쿼리로 | **OPTIMADE**, NERSC Superfacility API, Globus |

### 1-2. 물리적 저장 — 계층형(디스크 → 테이프)

| 시설 | 저장 방식 |
|---|---|
| **DESY PETRA-III** | 연간 약 **4.5PB 디스크**, **180일 보존** → **테이프 2부** |
| **Diamond** | 생성일로부터 **최소 30일** 온라인 → **장기보존 아카이브 사본 1부** |
| **ESRF** | DOI 부여 원시데이터 **최소 10년**, **메타데이터는 영구** |
| **NERSC** | Community File System(디스크) + **HPSS 테이프**('23년 말 **2.57억 파일 380PB**) |

### 1-3. 개방 — 엠바고 후 자동 공개

**3년 엠바고가 사실상 국제 표준**이다.

- **ESRF** : 실험팀 **3년 단독 접근**(연장 가능) → 이후 공공재원 연구 데이터는 **CC-BY-4로 공개**, 공공재원 실험은 **DOI 자동 생성**
- **Diamond** : 데이터 생성일 기준 **3년**, 기간 중 실험팀만 접근
- **ISIS** : **3년** 후 공개

핵심은 **공개 여부를 연구자가 결정하지 않는다**는 점이다. 기본값이 공개이고 엠바고는 시간만 벌어준다.

### 1-4. 보안 — 등급이 아니라 연합 인증

기초연구 데이터라 기밀등급보다 **연합 신원관리**로 푼다(LBNL Superfacility 프로젝트 기준).

- **OIDC / SAML** 프로토콜
- **InCommon Federation** 회원과 DOE 관리 시설로 범위 설정
- **비(非)DOE 기관은 SIRTFI**(조직 보안 모범사례)와 **REFEDS MFA Profile** 준수 요구
- **영구 자격증명(사용자명·API 키) 공유 회피**, **자동 갱신 임시 토큰** 사용
- **S3M(Secure Scientific Service Mesh)** — 외부 서비스와 내부 HPC 사이에 정책 집행·라우팅·인증·인가·트래픽 관리

### 1-5. 연계 API — 세 종류

- **시설↔HPC 제어** : **NERSC Superfacility API**(`api.nersc.gov/api/v1.2/`). `/compute`(작업 제출·상태), `/storage`(데이터 이동). 목표는 컴퓨팅부터 스토리지까지 완전 자동화된 이용
- **DB 연합 질의** : **OPTIMADE** — **JSON:API 기반 공통 REST 규격**. **base URL만 바꿔 같은 쿼리**를 던지면 다른 DB에서도 동작. **22개 제공자의 25개 상호운용 DB, 2,200만+ 결정구조**, v1.2
- **이동·발행** : **Globus** — **MDF**(NIST·CHiMaD 지원, **80TB·1,000여 데이터셋**), **DLHub**, **Foundry-ML**이 그 위에 구축

## Ⅱ. 자율실험 데이터의 특수성 — 두 갈래로 갈린다

대형시설 모델을 그대로 가져오면 **한 층이 빠진다.**

| 종류 | 성격 | 저장 |
|---|---|---|
| **원시 측정 blob**(이미지·스펙트럼) | 크고, 재접근 드묾 | **디스크 → 테이프** (대형시설과 동일) |
| **이력·메타데이터**(로봇 동작·파라미터·AI 결정) | 작지만 매우 많고 **항상 조회됨** | **상시 온라인 DB** — 테이프 부적합 |

**이유** : AI가 다음 실험을 계획하려면 과거 이력을 계속 읽어야 한다. **이력은 식지 않는다. 그것이 곧 학습 데이터다.**

**실제 구현이 그렇다.**
- SDL 실무 : 모든 워크플로·입력·출력·모델 버전의 **완전한 로그를 객체 또는 문서 저장소에 엄격한 스키마 검증**과 함께 저장
- **AlabOS**(버클리 A-Lab) : **MongoDB**로 유연한 스키마 + **시료 위치 포함 실시간 메타데이터 추적**
- **Bluesky** : databroker(MongoDB) → **Tiled + PostgreSQL 전환 중**, NSLS-II가 **최소 2027년 4월까지** databroker 유지. Tiled는 검색·원격 슬라이싱·포맷 변환·**실시간 스트리밍** 제공

**대형시설도 이미 같은 구분을 한다** — ESRF는 **원시 10년 / 메타데이터 영구**, SciCat·ICAT은 **데이터를 저장하지 않고** 검색 가능한 기술만 제공.

### 2-1. 보존 3단 판단

| 구분 | 처리 |
|---|---|
| **무조건 영구 온라인** | 이력·메타데이터·AI 의사결정 (용량 작음) |
| **선별 보존** | 원시 blob — 온라인 축약 후 대표본만 남기고 테이프 |
| **요약만** | 고빈도 센서 원신호(초당 수백 샘플의 온도·압력) — 통계값만, 원신호는 단기 후 폐기 |

## Ⅲ. 공개유예(엠바고) 기간의 근거 지표

### 3-1. 정량 지표 3종

| 지표 | 정의 | 값 |
|---|---|---|
| **인용 반감기**(Cited Half-Life) | JCR이 저널·주제별로 발표. **인용된 논문의 중위 연령**, "지식의 회전율" | 컴퓨터과학 **약 6년** / 정보학 저널 14년 / 인문학 저널 32년·단행본 40년 |
| **Price Index** | 전체 인용 중 **5년 이내 문헌 비율**. 클수록 연구전선이 빠름 | 물리학 **60~70** / 사회학 40~45 |
| **기술주기(TCT)** | **특허가 인용한 선행특허의 중위 연령**. 기술 자체의 회전속도 | 빠른 전자 **5~6년** / 느린 기계 **12~15년**. 정규화 TCT: 제약(424) 1.02 vs 메모리칩(711) 0.79 |

→ 대략의 눈금은 **IT·전자 5년, 소재·기계·제약 10년 이상**.

**단서** : Communications of the ACM에 *"컴퓨팅 연구의 급속한 진부화는 신화"* 라는 반론이 있다. 또 이 지표들은 엄밀히는 "지식이 쓸모없어진 시점"이 아니라 **"연구자들이 얼마나 최근 문헌을 인용하는가"** 를 재는 대리지표다.

### 3-2. 제도적 참조점

| 제도 | 기간 |
|---|---|
| 대형연구시설 엠바고(ESRF·Diamond·ISIS) | **3년** (연장 가능) |
| 미국 기밀 자동해제(E.O. 13526) | **생산 25년 후 자동해제**. 예외 50년, 인적정보원(50X1-HUM) 최대 75년, **75년 초과는 극히 예외적** |
| 국내 공공기록물 보존기간 | 1·3·5·10·30년·준영구·영구. **비밀기록물은 생산 시 비밀보호기간과 보존기간을 함께 지정** |

## Ⅳ. 국외이전 — 국내 현행과 미·일 비교

### 4-1. 국내 현행 = 국적 기준

**「국가연구개발사업 보안대책」**(과기정통부 행정규칙)

- **보안과제에 대한민국 국적을 가지지 않은 외국인의 참여**는, 내국인을 통한 목적달성이 어려울 경우 **보충적으로 인정**하는 것이 원칙
- 외국인 참여 시 **1개월 이내**에 ▲협약사항 ▲참여 외국인 신상 ▲과제 참여 범위 ▲**정보 접근 권한의 범위**를 중앙행정기관장에 보고하고 **국가정보원장에게 통보**

**산업기술보호법** — 국가핵심기술 수출은 **사전 승인**, 승인 대상 외에도 **신고 및 수리**(개정으로 '수리를 요하는 신고'임이 명확화). 신청 시 **45일 이내 관계부처 협의 + 위원회 심의**. **국가핵심기술 판정 신청 제도**도 존재.

**⚠ 다만** 학계 분석상 **산업기술의 범위는 제품·공정 구현에 필수적인 기술정보로 한정**되고, **개발 과정의 부수적 실험데이터는 영업비밀 영역으로 위임**된다. 연구데이터를 포함하려면 **입법적 해결이 필요**하다. 즉 자율실험 데이터 대부분은 애초에 이 법의 그물에 걸리지 않는다.

**진행 중** — **국가연구개발혁신법 개정안이 2026.1.29 국회 통과**(참석 225명 전원 찬성), **2026.2.19 공포, 8.20 시행** 예정. **연구보안 체계 전면 개편**, **연구보안 전담기관 설치**, 시행령상 **「민감과제」 신설**(보안과제와 일반과제의 중간 등급 — 보안과제 일괄 확대에 따른 연구기관 부담 없이 잠재적 중요기술을 선제 보호).

### 4-2. 미·일 판정 기준 비교

**수출통제 층위**

| | 미국(EAR/ITAR) | 일본(외환법) |
|---|---|---|
| 기준 | **국적·시민권** | **거주자성** |
| 판정 | 외국인에게 국내에서 공개해도 **국적국으로 수출한 것으로 간주**(deemed export). 물리적으로 아무것도 안 나가도 성립 | **입국 후 6개월 경과** 또는 **일본 내 사무소 근무** 시 거주자 → 관리대상 아님 |
| 예외 | 영주권자·미국 포함 이중국적자는 외국인 아님 | — |

**연구보안 층위 — 미·일이 수렴했다**

| | 미국 MFTRP (CHIPS and Science Act §10638) | 일본 特定類型 (2022.5.1 시행) |
|---|---|---|
| 계약·지휘 | 외국 정부·기관이 제공하는 지위·활동 | 외국 정부·법인과 고용계약, 지휘명령·선관주의의무 |
| 금전 | 현금·현물·연구비·장래보상·무상 해외여행·명예직함·경력기회 등 | **연간 소득의 25% 이상** 경제적 이익(장학금 포함) |
| 지시 | 외국 정부 또는 그 지정자 | 국내에서 **외국 정부 등의 지시 하에 행동** |
| **국적** | **무관** — NSPM-33은 *"시민권이나 출신국에 관계없이"* 로 명시 | **무관** |

- 미국 : **USICA에 포함됐던 Safeguarding American Innovation Act**가 **CHIPS and Science Act(2022)** 로 옮겨 담김. NSF 연구보안정책실, 연구보안 교육 의무, MFTRP 참여 금지, 우려국 계약·기부 공시
- 일본 : 거주 기준이라는 헐거운 바닥은 유지하되 **미국식 관계 기준을 얹은 것**. 대학은 2022.5 이후 신규 채용 시 **특정유형 해당 여부 서약서**를 받으며 **비상근 강사·RA·TA까지** 포함

**정리** : 한국은 **국적 기준 하나**로 버티고 있어, 외국인 연구자는 일률적으로 걸리고 내국인은 외국 정부 자금을 받아도 걸리지 않는 **비대칭**이 있다. 거주 기준도, 관계·보상 기준도 국내엔 없다.

## Ⅴ. 공동연구는 어떻게 처리하는가 — 미·일 공통 예외

**두 나라 모두 공동연구를 막지 않고, "공개할 연구인가"로 가른다.**

### 미국 — 기초연구 면제(Fundamental Research Exclusion)

- **NSDD-189** : 기초연구 = *"결과가 통상 공개되고 과학계에 널리 공유되는 과학·공학 분야의 기초·응용 연구"*
- **EAR §734.8** : **기초연구에서 나오고 공개될 예정인 기술·소프트웨어는 EAR 적용 대상이 아님**
- 미국 대학 연구는 원칙적으로 기초연구로 간주되며, **연구 참여 인력의 국적에 대한 후원자 제한이 없다**
- **면제가 깨지는 조건** : **발표 제한 또는 접근·배포 제한을 수용하는 순간** 기초연구가 아니게 된다(독점정보 보호를 위한 제한적 검토는 예외)

### 일본 — 공지 기술·기초과학 연구 예외

- 외환법 **역무통달**상 **기초과학 분야 연구활동**, **학회발표·논문·특허출원 등으로 공지가 된 기술**은 관리 대상 밖
- **리스트 규제 기술이라도** 공지 기술 제공이거나 기초과학 연구활동이면 특례로 허가 불요
- 즉 일본은 **거주 기준(누구에게) + 공지·기초연구 예외(무엇을)** 를 겹쳐 쓴다

## Ⅵ. 〈자체 제안〉 설계

### 6-1. 판정 순서 — 이 순서가 핵심

> **① 공개 예정 기초연구인가?** → 그렇다면 **자유** (미·일 공통 예외)
> **② 아니라면, 누구에게 주는가?** → **거주·소속 기준** (일본식)
> **③ 그 사람이 외국 정부와 계약·자금 관계인가?** → **관계 기준** (미·일 수렴)
> **④ 이중용도 스크리닝에 걸리는가?** → **개별 심사**

**①이 대부분을 걸러준다.** 그래서 ①을 명시하는 것이 규제를 만드는 것보다 중요하다.

### 6-2. 항목별 기준

| 항목 | 기준 |
|---|---|
| **접근** | 엠바고 중에는 실험팀·수행기관에 한정. 접근 권한 부여 시 **범위와 이력을 기록**(현행 보안대책의 '정보 접근 권한의 범위' 서식 활용) |
| **소유권** | 사업 협약 단계에서 사전 규정. 자율실험 서비스 이용 시 **이용자–서비스 사업자 간 귀속**을 표준계약서로 |
| **이차이용** | 엠바고 종료 후 **CC-BY 기본값**. AI 학습 이용을 명시적으로 허용 범위에 포함 |
| **공개유예** | **기본 3년**(국제 관행 정합, 연장 조항). 분야별 차등 시 **TCT·인용 반감기**를 근거로 — AI·컴퓨팅·전자 2~3년, 소재·화학·바이오 5년 |
| **국외이전** | §6-1의 4단계 판정. **"이전"에 파일 전송뿐 아니라 국외 접근권 부여 포함** |

### 6-3. 이중 트랙 — 시간 기반과 심사 기반을 분리

**시간 기반 엠바고는 경쟁력 보호에는 맞지만 안보 위험에는 맞지 않는다.** 기술 경쟁력은 시간이 지나면 감가하지만, **이중용도 위험은 줄지 않는다**(병원체 서열·독성물질 합성경로는 30년 뒤에도 위험). 미국이 기밀에 25년 자동해제를 두면서도 특정 범주를 75년까지 빼두는 이유다.

| 트랙 | 방식 |
|---|---|
| **경쟁력 보호용** | 시간 기반 **자동 해제**(3년 기본, 분야별 차등) |
| **이중용도 위험용** | 기간 만료로 자동 공개되지 않게 하고 **재심사 후 해제**. 공공기록물법의 "생산 시 비밀보호기간과 보존기간 동시 지정" 구조 준용 |

### 6-4. 구현 원칙

1. **통합 저장소를 짓지 않는다** — 데이터는 생산 시설에 두고 **카탈로그 + 공통 API**로 연결. 국내엔 이미 **DataON·ZEUS**가 있으므로 필요한 것은 새 저장소가 아니라 **자율실험 데이터용 메타데이터 스키마와 API 규격**
2. **3계층 스토리지를 갖춘다** — DB(문서/관계형) + 객체 스토리지 + 테이프. 흔한 실수가 **테이프 아카이브만 준비하고 상시 조회 DB를 빠뜨리는 것**
3. **보존기간을 종류별로 정한다** — "실험데이터" 일괄이 아니라 ESRF처럼 **원시 10년 / 메타데이터 영구** 식으로
4. **보내지 말고 접근시킨다** — 엠바고 중 데이터는 국내 보관 + 원격 접근. 물리적 이전이 없고 접근 이력이 남는다. 연합학습도 선택지
5. **OPTIMADE 모델을 차용한다** — 중앙집중이 아니라 **공통 쿼리 규격 통일**. 각자 DB를 만들어도 규격 하나만 맞추면 연합이 된다

### 6-5. 제도 접목

- **2026.8 시행 개정 혁신법의 「민감과제」 분류에 자율실험 데이터를 올리는 것**이 가장 자연스럽다. 신설 **연구보안 전담기관**이 운영 주체
- **국가핵심기술 해당 시**는 기존 산업기술보호법 절차에 따르고, 애매하면 **국가핵심기술 판정 신청** 경로를 안내
- **관계·보상 기준(MFTRP형) 도입**은 국가연구개발 보안체계 전반의 문제이므로 **검토과제로만** 언급

## Ⅶ. 〈자체 제안〉 본문 문안(안)

**□ (데이터 거버넌스) 자율실험 데이터의 접근·소유권·이차이용·공개유예·국외이전 기준을 수립**

※ **(저장·연계)** 통합 저장소 신설 대신 **데이터는 생산기관이 보관하고 메타데이터 카탈로그와 공통 API로 연계**하는 연합 구조 채택(OPTIMADE·SciCat 모델 참조). **DataON·ZEUS 등 기존 국가 플랫폼과 접속**하고, **이력·메타데이터는 상시 온라인 DB, 원시 측정데이터는 계층형 보존**으로 **종류별 보존기간을 구분**(ESRF: 원시 10년·메타데이터 영구)
※ **(공개유예)** **기본 3년**의 공개유예 후 **DOI 부여 및 개방**을 원칙으로 하되(ESRF·Diamond·ISIS 관행), 분야별 차등이 필요한 경우 **인용 반감기·기술주기(TCT) 지표**를 근거로 설정
※ **(국외이전)** **공개를 전제로 수행되는 기초연구 데이터는 자유 이전**을 명시(미국 기초연구 면제, 일본 공지기술·기초과학 예외 참조). 다만 **협약에 발표 제한 또는 참여자 제한 조항이 포함되면 별도 검토 대상**으로 전환. **"이전"에 국외 접근권 부여를 포함**하고, 엠바고 중 데이터는 **국내 보관·원격 접근**을 원칙으로 접근 범위와 이력을 기록
※ **(위험 데이터)** 이중용도 스크리닝 대상 데이터는 **기간 만료에 따른 자동 공개에서 제외**하고 재심사를 거쳐 해제
※ **(제도 접목)** 2026.8 시행 「국가연구개발혁신법」 개정에 따른 **「민감과제」 분류 및 연구보안 전담기관 체계**에 자율실험 데이터를 편입

## Ⅷ. 한계

1. **자율실험실 전용 데이터 정책은 확인되지 않았다.** Ⅰ의 사례는 대형 시설(방사광·중성자)과 소재 DB 정책이며, SDL 고유 데이터(로봇 조작 이력·AI 의사결정 로그)에 대한 별도 정책은 국제적으로도 아직 없다(NIST의 "데이터·지식 관리 표준"이 개발 중인 것과 같은 맥락).
2. **개정 혁신법의 「민감과제」 분류 기준 세부와 연구보안 전담기관의 역할**은 시행령·하위규정 원문 확인이 필요하다.
3. **실험데이터가 산업기술보호법상 '산업기술'에 해당하는지**는 학계에서도 입법적 해결이 필요하다고 보는 사안으로, 본 문서에서 결론 낼 성격이 아니다.
4. 한 자료에 "한국은 연구자의 해외 인재유치 프로그램 참여를 제한하거나 사전 신고를 의무화한다"는 취지의 서술이 있었으나 **근거 조문을 확인하지 못했다.** 원문 대조 필요.
5. DOE의 FISMA 등급·CUI 격리구역 운영 방식은 확인되지 않았고, **연합 인증 부분만** 확인된 내용이다.
6. **Ⅵ·Ⅶ은 전적으로 자체 제안**이며 관계기관과 검증된 바 없다.
