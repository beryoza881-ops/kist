## 공통 구성

1. **한눈에 보기 박스** — 최상단 별도 박스, 2~3문장 요약
2. **표 1. 자율실험실(폐루프 SDL) 주요 사례**
   - 기관·기업 / 실험실·조직(담당자) / 주요 분야 / 주요 성과 / 자율실험 정도
3. **표 2. (별도 구분)** 자율실험실은 아니지만 실험 자동화·AI 실험설계·드라이랩에 해당하는 사례
4. **참고 섹션** — 정책·생태계 동향과 현재의 한계
5. **출처** — 본문 인용 단어마다 하이퍼링크 + 문서 말미 번호순 리스트

## 자율실험 정도 척도

| 표기 | 의미 |
|---|---|
| ★★★ | 설계–실험–분석–재설계가 폐루프로 무인 순환 |
| ★★☆ | 실험 전 과정 자동화 + AI 부분 적용 (사람 개입 일부 잔존) |
| ★☆☆ | 구축 착수·개별 공정 자동화 단계 |

## 다시 빌드하기

```bash
npm install docx
node build_report.js          # ① 대학·출연(연) 편
node build_report_company.js  # ② 기업 편
```

모든 사례·수치는 공개 보도자료 및 기관·기업 발표 내용을 인용했으며, 인용 위치마다 출처 하이퍼링크가
걸려 있다. 기업 내부 구축 현황은 비공개인 경우가 많아, 표에 없는 기업이 자율실험실을 운영하지 않는다는
뜻은 아니다.

포항가속기연구소(PAL)는 공개 자료에서 폐루프 자율실험 운영 근거를 찾지 못해, 자율실험실을 뒷받침하는
대형 분석 인프라로 보아 표 2에 배치하고 해당 사실을 표 안에 명시했다.
