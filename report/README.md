## 구성

1. **한눈에 보기 박스** — 자율실험실의 정의와 국내 현황을 3문장으로 요약 (문서 최상단, 별도 박스)
2. **표 1. 자율실험실(폐루프 SDL) 주요 사례** — 9건
   - 컬럼: 기관 / 실험실·조직(담당자) / 주요 분야 / 주요 성과 / 자율실험 정도
   - KIST 계산과학연구센터, 한국재료연구원 오토노머스 랩, 한국화학연구원 화학데이터기반연구센터,
     KAIST 서동화 교수팀×포스코홀딩스, 한국에너지기술연구원 청정연료연구실, UNIST·IBS 합성 연구단,
     서울대 최장욱 교수팀, AI-네이티브 첨단바이오 자율실험실 6곳, 한국제약바이오협회 SDL 실습교육장
3. **표 2. (별도 구분)** 자율실험실은 아니지만 실험 자동화·AI 실험설계·드라이랩에 해당하는 사례 — 7건
4. **참고. 정책·생태계 동향과 현재의 한계** — 협의체·분야별 확산·표준화 과제
5. **출처** — 28건, 본문 해당 단어에 하이퍼링크 + 문서 말미 번호순 리스트

## 자율실험 정도 척도

| 표기 | 의미 |
|---|---|
| ★★★ | 설계–실험–분석–재설계가 폐루프로 무인 순환 |
| ★★☆ | 실험 전 과정 자동화 + AI 부분 적용 (사람 개입 일부 잔존) |
| ★☆☆ | 구축 착수 단계 (설비 도입·설계 진행 중) |
